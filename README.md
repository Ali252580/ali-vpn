# ali vpn 🦊

نصب و راه‌اندازی خودکارِ کلاینت **Arman VPN** (کلاینت غیررسمی Mozilla Firefox VPN) روی ویندوز — با ریلهٔ ضد فیلتر، سازگار با اینترنت ایران.

## این پروژه چیست؟

Mozilla VPN / Firefox IP Protection در ایران با خطای **HTTP 451 (unavailable_in_region)** بلاک است. این پروژه ۳ کار می‌کند:

1. **اسکریپت‌های ویندوز** برای اجرا و تنظیم سریع کلاینت Arman
2. **کد Worker آمادهٔ Cloudflare** برای ساخت «ریلهٔ شخصی» مخصوص خودتان (چند کیلوبایتِ درخواست‌های ورود از راه آن می‌روند؛ کل اینترنت از تونل VPN)
3. **راهنمای فارسی گام‌به‌گام** برای اتصال دامنهٔ رایگان (`us.kg` / `dpdns.org`) به Cloudflare

پس از این تنظیم، دیگر نیازی به «فیلترشکن دوم» نیست — برنامه خودش همه‌چیز را خودکار حل می‌کند.

## محتویات

| فایل | توضیح |
|---|---|
| `setup.ps1` | تنظیم خودکار کلاینت از طریق API محلی (DNS، ریله، حالت ضد فیلتر) |
| `worker.js` | کد آمادهٔ Cloudflare Worker برای ریلهٔ شخصی |
| `آموزش-گام-به-گام.txt` | راهنمای فارسی ساخت ریلهٔ شخصی (دامنهٔ رایگان + Cloudflare) |
| `فیلترشکن.bat` | اجرای سریع کلاینت |
| `راهنمای فارسی.txt` | راهنمای کلی استفاده |

## شروع سریع

### ۱. کلاینت Arman را نصب کنید
آخرین نسخه از [github.com/armanlife/arman-vpn-client](https://github.com/armanlife/arman-vpn-client) و وارد شوید (حساب Mozilla VPN لازم است).

### ۲. ریلهٔ شخصی بسازید (۵ دقیقه، رایگان)
راهنمای کامل با تصویر قدم‌ها: [`آموزش-گام-به-گام.txt`](آموزش-گام-به-گام.txt)

خلاصه:
1. در [domain.digitalplat.org](https://domain.digitalplat.org) دامنهٔ رایگان بگیرید (مثل `myali.us.kg`)
2. دامنه را در اکانت Cloudflare خود Add کنید (NSها را در پنل دامنه بگذارید)
3. یک Worker بسازید، محتوای `worker.js` را Paste کنید (با یک secret تصادفی) و Deploy بزنید
4. روی Worker تب Settings → Domains & Routes → Add → **Custom domain** → `relay.myali.us.kg`
5. تست: `https://relay.myali.us.kg/?secret=SECRET&health=1` باید `{"relay":"arman-vpn",...,"ready":true}` بدهد

### ۳. اسکریپت را اجرا کنید

```powershell
.\setup.ps1 -RelayUrl "https://relay.myali.us.kg/?secret=YOUR_SECRET"
```

این اسکریپت به‌طور خودکار:
- سرور رلهٔ شخصی را در کلاینت ثبت می‌کند
- DNS را روی سندباکسِ پاس‌شده (`8.8.8.8` به‌طور پیش‌فرض) می‌گذارد
- «شکستن Hello» را روی `sni` و ECH را خاموش می‌کند (بهینه برای ایران)
- حالت proxy شفاف (`clear`) ذخیره و اتصال را روشن می‌کند

### ۴. استفاده
پروکسی SOCKS5 برنامه روی `127.0.0.1:10810` است (همچنین HTTP proxy). داشبورد: `http://127.0.0.1:10820/app/`

## نکته‌های مهم برای ایران

- آدرس‌های `*.workers.dev` در ایران با DPI مسدودند؛ **حتماً Custom domain** روی Worker بگذارید
- از DNS‌ها فقط `https://8.8.8.8/resolve` پایدار بود؛ 1.1.1.1 و Quad9 معمولاً بلاک‌اند
- اگر موقتاً خطا داد، برنامه خودش بعد از چند دقیقه دوباره تلاش می‌کند — کاری لازم نیست بکنید.
- رمز (secret) خود را هیچ‌جا منتشر نکنید.
